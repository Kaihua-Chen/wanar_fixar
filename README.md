# WanAR + FixAR project website

Project page: https://kaihua-chen.github.io/wanar_fixar/

Paper PDF: https://kaihua-chen.github.io/wanar_fixar/static/paper/wanar_fixar.pdf

Static research project website for **Hierarchical Diffusion for Camera-controlled Autoregressive Video Generation**.

## Publishing

GitHub Pages publishes the `main` branch from the repository root. `.nojekyll` keeps the site as plain static files.

To update the paper, replace `static/paper/wanar_fixar.pdf` and push to `main`. The Paper button uses this local PDF and works before arXiv is available. Add real arXiv and code links in `index.html` when they become available, and update the citation.
